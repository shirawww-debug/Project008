Analyser une vraie capture

Capture .pcap de trames Action 802.11 (voir scripts/capture_bfi.sh). Le serveur a besoin de scapy (pip install scapy). Un journal CSV d'étiquetage optionnel (t_debut,t_fin,label) déclenche l'entraînement supervisé.

Ce qu'on peut — et ne peut pas — savoir

Les BFI sont un capteur de canal radio, pas une caméra. Cadre les attentes avant d'interpréter les résultats.

✓ Solide

  • Présence / absence dans la zone couverte
  • Comptage grossier (0, 1, quelques personnes)
  • Mouvement vs immobilité ; activité grossière (marche, chute)
  • Rythme respiratoire au repos (courte distance, sans obstacle)
  • Localisation par zones apprises (après entraînement)

~ Fragile

  • Ré-identification (« Alice vs Bob ») : ensemble fermé, même lieu, box fixes, fenêtre courte. Se dégrade si l'environnement change. Pas une biométrie portable.
  • Gestes / activités fines : surtout en labo contrôlé

✗ Hors de portée

  • « Voir à travers les murs » / dresser le plan du logement (demande un radar mmWave/UWB)
  • Identifier un inconnu jamais enregistré (supervisé)
  • Lire l'écran, la frappe clavier, les paroles
  • Suivre quelqu'un d'un réseau à l'autre

La résolution dépend du nombre de clients connectés à la box (chaque client = un point de vue sur la pièce). Détails : README.md, docs/ETHICS.md.
